# =============================================================================
# Package Notes for ARM64:
# =============================================================================
#
# 1. OpenBLAS: NumPy/SciPy use OpenBLAS for linear algebra on ARM64
#    - Installed via apt: libopenblas-dev
#    - Provides significant performance improvement over reference BLAS
#
# 2. ONNXRuntime: Use onnxruntime (not onnxruntime-gpu)
#    - ARM64 support via official wheels
#    - Falls back to CPU inference
#
# 3. Pillow-SIMD: Consider pillow-simd if building from source
#    - Provides ARM NEON optimizations
#    - Standard Pillow also works well on ARM64
#
# 4. Excluded packages:
#    - tensorflow (too heavy for RPi, ~2GB)
#    - torch (use ONNX for inference instead)
#    - opencv-python-headless (use pillow + scikit-image)
#
# 5. Memory considerations:
#    - Total installed size: ~500MB
#    - Runtime memory: varies by workload
#    - Recommend 4GB+ RAM for comfortable operation
#
# =============================================================================
