# Negative Space Project: Module Overview

This directory contains the core modules for negative space analysis, mapping, and blockchain integration.

## Modules
- `negative_space_reconstructor.py`: 3D reconstruction and negative space extraction
- `negative_space_coordinates.py`: Negative space region identification and signature generation
- `multi_object_mapper.py`: Multi-object mapping and temporal tracking

## Tests
Unit tests for each module are in `src/tests/`.
